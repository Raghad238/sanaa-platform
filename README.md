"# Sana'a Wedding Marketplace Platform

A web platform for discovering wedding vendors, services, and products in Sana'a, Yemen. The project is designed as a marketplace for wedding preparation and celebration needs while preserving the core marketplace model of public discovery, seller management, and admin moderation.

## Scope

- Public discovery of wedding-related stores, products, and services.
- Seller storefronts for wedding vendors and service providers.
- Admin moderation and catalog management.
- Dynamic categories for wedding categories and subcategories.
- Subscription and trial rules aligned with the current product plan.

## Architecture

- Frontend: Next.js + TypeScript + Tailwind CSS
- Backend: Node.js + Express.js + TypeScript
- Database: MySQL 8+ + Prisma
- Validation: Zod
- Authentication: JWT + HTTP-only cookies
- Package manager: pnpm
- Environment: Docker

This repository remains a monorepo and is intentionally scoped to the current implementation day and documentation checkpoints."
